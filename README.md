# Customer Segmentation Web App

A simple and interactive web application developed using **Python, Streamlit, and K-Means Clustering** to analyze and group customers based on their purchasing behavior.

## Features
- Customer segmentation using K-Means clustering
- Interactive data visualizations
- Customer data analysis
- Elbow Method and Silhouette Score analysis
- Predict customer segments

## Technologies Used
- Python
- Streamlit
- Pandas & NumPy
- Scikit-learn
- Matplotlib, Seaborn & Plotly

## How to Run

1. Clone or download this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the Streamlit application:

   `streamlit run app.py`

## Project Goal

To identify different customer groups using machine learning and help businesses understand customer behavior for better marketing decisions.
